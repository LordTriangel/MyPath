# OnPath 0.18.5 – Nothing gets lost quietly

**Tours**
- **An interrupted tour always gets its question** („Weiter / Speichern / Löschen“) – also when the phone could not read it at the first try after a restart. Before, a new tour could then close it as finished without asking.

**Planning**
- **A place's menu always opens** – also when the plan changed while the menu was being worked out (for example right after the first route was drawn). Before, it could stay closed without a word.

**Maps**
- A map package the server could not build is asked for only once per app start (before: again on every map move – harmless, but needless traffic).
