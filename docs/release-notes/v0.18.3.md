# OnPath 0.18.3 – A stop on the line is set at once

**Planning**
- **A stop (or any point) set right on the calculated route splits it there at once** – nothing is calculated again, the line, distance, climb and time stay exactly the same. Long multi-day plans gain the most. The browser planner does the same since 0.18.2.

**Inside**
- First pieces of live sharing are in the app, switched off – nothing you see changes yet.
